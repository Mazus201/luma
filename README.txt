Ярлыки MSI Mystic Light

Ярлыки на рабочем столе переключают зоны материнской платы:
- Подсветка — красный
- Подсветка — синий
- Подсветка — оранжевый
- Подсветка — белый
- Подсветка — бирюзовый
- Подсветка — выключить
- Подсветка — ярче 10%
- Подсветка — тусклее 10%

Приложение использует официальный MSI Mystic Light SDK. При выключении Luma переводит зоны в статический режим, устанавливает яркость в 0 и отправляет чёрный цвет. Если устройство не принимает яркость 0, чёрный цвет остаётся запасным способом выключения. Фактическое поведение зависит от модели устройства и версии MSI Center.

Рабочие ярлыки и горячие клавиши находятся в меню «Пуск» → «Luma». Ярлыки в папке `E:\light` остаются для ручного запуска: Windows не регистрирует назначенные им сочетания в этой папке.

Сочетания клавиш:
- Красный — Ctrl+Alt+Shift+3; синий — Ctrl+Alt+Shift+5; оранжевый — Ctrl+Alt+Shift+4.
- Белый — Ctrl+Alt+W; бирюзовый — Ctrl+Alt+Shift+2; выключить — Ctrl+Alt+Shift+0.
- Ярче — Ctrl+Alt+Shift+↑; тусклее — Ctrl+Alt+Shift+↓.

Автозапуск зарегистрирован в Планировщике заданий как `MysticLightShortcuts\LumaStartup`; он запускает приложение через 20 секунд после входа пользователя. Окно скрыто, значок находится в области уведомлений.

Чтобы обновить ярлыки и задачи после переноса приложения, запустите RegisterHotkeyTasks.ps1 из этой папки. Скрипт по умолчанию ищет актуальную сборку в `E:\light\LumaFinal\LumaFinal.exe`. Если приложение расположено в другом месте, передайте путь явно:

    .\RegisterHotkeyTasks.ps1 -ExePath "C:\путь\к\Luma.exe"

Команды горячих клавиш пишут подробности ошибок в %LOCALAPPDATA%\MysticLightControl\errors.log. Коды возврата: 0 — успех, 1 — неверные аргументы, 2 — ошибка подключения/Release SDK, 3 — общая ошибка, 4 — не изменена ни одна зона, 5 — частичный успех, 6 — SDK занят другим процессом.
